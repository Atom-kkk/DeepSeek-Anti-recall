# DeepSeek 防撤回（底层拦截 & 精装修 UI 终极版）

> 通过底层 XHR 拦截实现真防撤回：被撤回的回复在网页上绝不消失，并实时同步至本地精装修存档库。

- **版本：** 2026-10-25.70
- **作者：** lllzh & llllhhAtom-kkk
- **适用页面：** `https://chat.deepseek.com/*`

## 功能特性

| 能力 | 说明 |
| --- | --- |
| 底层 XHR 拦截 | 直接 Hook 网络请求层，在撤回生效前截获原始回复内容 |
| 网页不消失 | 被撤回的内容在原位保留，并标注「⚠️ 此回复已被拦截，仅在本浏览器存档」 |
| 本地存档库 | 基于 IndexedDB（`ds-anti-recall` / `messages`）持久化，按会话（sessId）与更新时间建索引 |
| 精装修归档器 | 内置分类对话归档视图，可浏览历史被撤回的回复 |
| 导入 / 导出 | 支持整库导出为 JSON、从 JSON 导入还原 |
| 写入节流 | 800ms 写入节流，避免高频请求导致存储压力 |
| 菜单入口 | 通过油猴菜单执行「清空记录 / 打开归档器 / 导出 / 导入」 |

## 安装

1. 先安装脚本管理器：[Tampermonkey](https://www.tampermonkey.net/) 或 Violentmonkey。
2. 新建脚本，把 `DeepSeek Anti-recall (Ultimate & Polished UI)-2026-10-25.70.user.js` 的全部内容粘贴进去并保存。
3. 打开 [chat.deepseek.com](https://chat.deepseek.com/)，脚本自动生效（控制台会输出 `[Anti-recall] 终极防撤回 & 精装修版启动`）。

## 使用

点击浏览器扩展栏中的脚本管理器图标，在菜单里选择：

- `📖 打开分类对话归档器` —— 浏览本地存档
- `📤 导出记录 (JSON)` —— 备份全部记录
- `📥 导入记录 (JSON)` —— 还原备份
- `🗑️ 清空所有本地记录` —— 清空 IndexedDB 存档

## 数据与隐私

所有数据仅保存在浏览器本地 IndexedDB，不上传任何服务器。清理浏览器站点数据会一并清除存档，建议定期导出 JSON 备份。
